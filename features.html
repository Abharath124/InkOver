Productivity

Global Keyboard Hotkeys

Keep your hands on the keyboard and switch tools seamlessly without opening menus.

Action / Tool Default Shortcut Description
Pen Tool Ctrl + Shift + 1 Activates freehand drawing pen with pressure sensitivity.
Highlighter Ctrl + Shift + 2 Draws a wide translucent stroke that highlights text without obscuring it.
Eraser Ctrl + Shift + 3 Erases individual ink strokes precisely.
Clear Screen Ctrl + Shift + C Instantly removes all current drawings from the screen.
Whiteboard Mode Ctrl + Shift + W Turns your screen into a blank whiteboard background.
Ghost Mode Ctrl + Shift + G Hides toolbar completely and lets you interact with apps underneath.
