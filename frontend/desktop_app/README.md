# InkOver - Real-Time Screen Annotation Software for Windows

Lightweight screen marker and drawing tool for Windows 10 & 11.
Draw, highlight, and write over any active desktop application (slides, video calls, charts, games, and web browsers) without freezing the screen.

---

## Quick Start (How to Run)

1. **Setup Installer:** Run `InkOver-Setup.exe` to install and create desktop shortcuts.
2. **Direct Portable Executable:** Double-click `InkOver.exe` to launch immediately with zero setup.

---

## Features & Controls

| Tool | Action | Description |
| :--- | :--- | :--- |
| **👆 Mouse (Ghost Mode)** | Click-Through | Lets mouse clicks and typing pass straight through to whatever window is behind it (Chrome, PowerPoint, Zoom). |
| **✏️ Pen** | Freehand Draw | Freehand drawing pen with smooth stroke interpolation. |
| **🖍️ Highlighter** | Highlight Text | Wide translucent highlighter stroke. |
| **🧹 Eraser** | Erase Strokes | Erases strokes under the cursor. |
| **📋 Board** | Whiteboard Mode | Toggles between Transparent desktop, Whiteboard, and Blackboard. |
| **🎨 Color Pip** | Pick Any Color | Opens native color selector to choose any shade. |
| **● Stroke Size** | Cycle Width | Cycles between 2px, 4px, 8px, and 16px. |
| **↩ Undo** | Undo Last | Removes the last drawn stroke (`Ctrl+Z`). |
| **🗑 Clear** | Wipe Screen | Clears all annotations (`C`). |
| **✖ Exit** | Quit | Closes InkOver. |

---

## Keyboard Shortcuts

* <kbd>1</kbd> — Activate Pen Tool
* <kbd>2</kbd> — Activate Highlighter
* <kbd>3</kbd> — Activate Eraser
* <kbd>G</kbd> — Ghost Mode (Toggle Mouse Click-Through)
* <kbd>C</kbd> — Clear Screen
* <kbd>Ctrl+Z</kbd> — Undo Last Stroke
